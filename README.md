# Minecraft Server Runner

لانچر چندسروره برای Windows. فایل `start.bat` هر سرور را یک‌بار اضافه کن، بعد یک سرور را انتخاب کن و `Run selected` بزن، یا با `Run all` همه را هم‌زمان اجرا کن. دکمه `Stop` همه‌ی سرورها را خاموش می‌کند.

مسیر سرورها ذخیره می‌شود و دفعه‌ی بعد خودکار در لیست می‌آیند. خروجی هر سرور هم با نام خودش در لاگ نمایش داده می‌شود.

## Build در GitHub

1. پروژه را push کن.
2. از تب **Actions** workflow را اجرا کن.
3. فایل JAR را از **Artifacts** دانلود کن.
4. Java 17 یا بالاتر لازم است.

این برنامه فقط Windows است و هر `start.bat` باید در پوشه‌ی همان سرور قرار داشته باشد.
